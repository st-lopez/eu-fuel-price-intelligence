# Data sources and reuse

Verified public page: https://energy.ec.europa.eu/data-and-analysis/weekly-oil-bulletin_en (2026-11-19). The Commission lists weekly prices including/excluding taxes, duties and taxes, and historical price developments from 2005 onwards (4.3 MB XLSX listed on that date). National submissions Wednesday, bulletin Thursday. Publication date is not the observation date.

Historical download link published by DG Energy in its newsletter: https://ec.europa.eu/newsroom/ener/newsletter-archives/77681 ; historical workbook: https://energy.ec.europa.eu/document/download/906e60ca-8b6a-44e7-8589-652854d2fd3f_en?filename=Weekly_Oil_Bulletin_Prices_History_maticni_4web.xlsx . Prefer the latest link on the bulletin page rather than assuming the URL is immutable. Public, no API key. No automated high-frequency scraping.

Commission report: https://op.europa.eu/o/opportal-service/download-handler?format=PDF&identifier=e0b9e5f3-daf4-11f0-8da2-01aa75ed71a1&language=en&productionSystem=cellar (historical file includes later corrections; most members from 2005, Bulgaria/Romania/Croatia from accession). Exact actual sheets, row headers, country series, units and file-specific notices remain unverified: binary retrieval failed with DNS resolution in the build environment. Do not infer completeness. Inspect the actual file before production parsing; record its checksum, date coverage, sheet labels, headers, country codes, units and missing markers. The synthetic fixture is not a source-schema replica.
